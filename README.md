# Telegram Mini Apps Backend

Универсальный backend API для обслуживания множества Telegram Mini Apps сайтов.

## 🎯 Возможности

- **Мультисайтовая архитектура**: Один backend обслуживает множество сайтов
- **Определение бота**: По домену, API ключу, query параметрам
- **Кэширование**: Redis + In-memory кэш для конфигураций
- **Rate Limiting**: Защита от DDoS и злоупотреблений
- **Firebase интеграция**: Использует Firestore из админ-панели
- **Генерация страниц**: Поддержка PageGenerator
- **Масштабируемость**: Готово к работе с сотнями ботов
